# 代理小组件

在 macOS 的桌面或通知中心“编辑小组件”里选择 **Proxi → 代理小组件**。中尺寸卡片显示最近确认的代理状态、配置名称、连接检测结果与时间，并提供开启、关闭和至多两个配置入口。点击沿用主程序本机控制接口的权限、恢复设置和错误处理；控制接口关闭或设为只读时，操作不会绕过限制。

共享快照仅含配置 ID、显示名称、状态、操作中/部分失败标志和时间，不含服务器地址、账号密码或控制密钥。主程序停止或快照超过十五分钟时标为缓存状态；组件不是实时网络监控。健康检测显示的是主程序最近完成的检测时间，而非每次打开组件的时间。

主程序在 App Group `group.com.whrss9527.proxyswitch.widgets` 中原子写入快照。发布前必须用同一 Apple 团队为主程序与扩展配置并验证共享组，实际安装 Developer ID 签名包，确认组件能读取状态、选择配置并执行点击；没有共享容器时保留草稿，不能把 ad-hoc 编译当作可发布。组件 ID 是 `com.whrss9527.proxyswitch.widgets`，沙盒只声明本机共享组，不执行内核、不直接授权或读取钥匙串。

主程序与代理引擎保留 SwiftPM，`Packages/ProxiWidgets` 单独在 Linux 测试最小快照。`Scripts/build-widgets.sh` 用固定 XcodeGen 2.44.1 构建独立扩展，先签组件再签主程序。双架构和精简包均包含组件，精简时分别处理组件二进制并重新签名。CI 检查嵌入和 pluginkit 注册，真实图库显示、共享容器、点击、权限拒绝和升级后的保留仍需原生验收。

`PROXI_WIDGET_DIR` 只用于把主程序的快照写入隔离测试目录，不更改扩展的生产容器。测试不可使用真实用户共享目录。
